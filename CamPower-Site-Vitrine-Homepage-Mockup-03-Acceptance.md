## PRODUCT POSITIONING LOCK

The Site Vitrine communicates CamPower as a platform connecting:

**Talents + Entreprises + Compétences + Opportunités**

with support for:

**Professional Profiles + Opportunities + Professional Networking + Recruitment + Missions**

The site vitrine must not be reduced to a conventional job-board proposition during implementation.

---

## SITE VITRINE / APPLICATION SEPARATION

The accepted experience model remains:

### SITE VITRINE

**Discover → Understand → Become interested → Access CamPower**

### CAMPOWER APPLICATION

**Search → Apply → Recruit → Network → Publish → Manage**

The site vitrine must not duplicate application functionality unnecessarily.

## PRIMARY APPLICATION CTA

Calls to action labelled:

**https://cam-power.net/**

## IMPLEMENTATION CONTENT CONDITION

Where Mockup 03 uses representative/demo application content, production implementation should preferentially use **authentic CamPower application screenshots and realistic CamPower/Cameroon content**.

Generic mockup data must not become an unsupported production claim.

In particular:

- do not imply relationships with organizations that have not been established;
- do not invent jobs or missions and present them as real;
- use Cameroon-appropriate content where representative content is required;
- use authentic CamPower screens wherever available.

This requirement does **not** reopen the approved visual design.

It is an implementation/content-fidelity requirement.
