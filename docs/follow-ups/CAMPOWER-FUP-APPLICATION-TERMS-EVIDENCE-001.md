# CAMPOWER-FUP-APPLICATION-TERMS-EVIDENCE-001

Status: **CLOSED — APPLICATION CGU CAPTURED 7 OCTOBER 2026**

Closed by `CAMPOWER-SITE-VITRINE-DSP-OWNER-REVIEW-RECONCILIATION-004`.

The live application conditions at `https://cam-power.net/cgu` were read in the browser on 7 October 2026. The page is titled Conditions générales d'utilisation. It states that the version has been in force since 21 July 2026. It covers the platform and the application: accounts, profiles, offers, short missions, user content, messaging, subscriptions, suspension, intellectual-property licence, liability, and Cameroonian law with the courts of Douala named for those CGU.

The Site Vitrine conditions page does not reproduce those obligations. It points to the application CGU and states that browsing the vitrine does not accept them. Acceptance, as the CGU itself states, occurs when an account is created.

This closure does not establish the legal operator. The CGU names HOPE CORPORATIONS. The application mentions légales name CamPower. That conflict stays in `CAMPOWER-FUP-LEGAL-OPERATOR-IDENTITY-001`.

Opened: 2 October 2026

This follow-up is separate from `CAMPOWER-FUP-APPLICATION-PRIVACY-EVIDENCE-001`. Privacy and contractual terms stay separate workstreams.

The Product Owner does not currently have the CamPower application source. Do not guess repository names or invent application rules.

- moderation;

- termination;
- intellectual-property licences for user content;

- application availability;
